# 📊 HR Analytics & Employee Attrition Project

An end-to-end Business Intelligence and Data Analytics project analyzing workplace factors driving employee attrition. This project integrates *Python* for exploratory data analysis (EDA) and data cleansing, *PostgreSQL* for relational data storage and complex query analysis, and *Power BI* for executive reporting and interactive dashboarding.


## 📌 Project Architecture & Workflow

1. Raw HR Data (Excel)

2. Python (Pandas / SQLAlchemy)
* Data hygiene & dropping zero-variance columns
* Missing value & data type validation
* Migration into relational database

3. PostgreSQL (Database)
* Stored cleaned records in structured schemas
* Solved core business problems via SQL aggregations

4. Power BI Desktop
* Built relational data models & DAX measures
* Designed interactive, theme-aligned visual dashboards


## 🛠️ Tech Stack & Tools

* *Data Cleaning & Manipulation:* Python (pandas, openpyxl)
* *Database Engine & ORM:* PostgreSQL, SQLAlchemy, psycopg2
* *Querying & Analysis:* SQL (Joins, Window Functions, Group By aggregations)
* *Visualization & BI:* Power BI Desktop (DAX, Interactive Filtering, Custom Layouts)


## 🔍 Key Business Insights

* *Overall Attrition:* The company recorded an overall attrition count of *237 employees* with an attrition rate of approximately *16%*.
* *High-Risk Roles:* *Laboratory Technicians (62), **Sales Executives (57), and **Research Scientists (47)* account for the highest employee turnover.
* *Demographics Impact:* The *25–34 age bracket* experienced the highest attrition (*116 exits*), highlighting early-to-mid career transition challenges.
* *Educational Background:* Employees from *Life Sciences (38%)* and *Medical (27%)* backgrounds form the largest share of attrited workforce.
* *Compensation & Satisfaction:* Average employee satisfaction sits at *2.73 / 4, with average monthly compensation around *$6.50K**.
